# Лабораторная работа №3: Дек с сегментированным буфером

Проект лабораторной работы №3 по информатике.

## Сборка проекта
Собрать основную программу и тесты:

```bash
make
```

После сборки создаются бинарные файлы:

- `build/lab3` — основная программа
- `build/lab3_tests` — модульные тесты

## Команды Makefile

Собрать проект:

```bash
make
```

Запустить полноэкранный интерфейс:

```bash
make run
```

Запустить модульные тесты:

```bash
make test
```

Удалить папку `build/`:

```bash
make clean
```

Полностью пересобрать проект:

```bash
make rebuild
```

Показать список доступных команд:

```bash
make help
```

## Примечание

Нужно `ncurses` для корректной работы проекта.
